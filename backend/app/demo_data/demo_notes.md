# DrugScreen360 Guided Demo Dataset

These files are bundled only to demonstrate the DrugScreen360 software workflow.

- Demo records are not experimental proof.
- Demo assay labels and feedback rows are not wet-lab results.
- Demo outputs must not be used for scientific conclusions, clinical decisions, regulatory submissions, or market-readiness claims.
- Use live public database records, curated real datasets, and qualified experimental review for research work.
