# DrugScreen360 Local Models

This folder is reserved for future real trained model files.

No local ADMET or toxicity model is included with the MVP. If no real model files are present and configured, the Local ADMET Model Adapter reports `unavailable` and does not generate predictions.

Large model artifacts are ignored by Git by default. Supported future artifact formats may include:

- `.pkl`
- `.joblib`
- `.onnx`
- `.json` metadata

Do not place private, licensed, or proprietary model files here unless you have permission to use them.
