# Example Reports

This folder is reserved for small, intentionally selected example reports.

Do not commit private, confidential, supervisor-only, or unpublished project reports. Generated reports should be reviewed before inclusion.

A good example report should include:

- App version.
- Research-use-only disclaimer.
- Clear model evidence status.
- External validation/calibration status when available.
- Honest missing-section warnings.
- No clinical, diagnostic, therapeutic, regulatory, safety, efficacy, approval, or market-readiness claims.

Generated reports are usually local artifacts and should remain untracked unless selected for documentation.
